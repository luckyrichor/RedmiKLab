# 测速重试说明卡片规格

## 目标

修复“设置测速地址”弹窗中“失败重试间隔”问号说明的位置问题，使说明紧邻对应设置项显示，并且不遮挡测速地址、输入值、单位或操作按钮。

## 已确认设计

1. 仅“设置测速地址”弹窗中的“失败重试间隔”采用内联说明卡片；主页面及其他设置项继续使用现有悬浮问号说明。
2. 点击问号后，在失败重试行正下方插入一张浅色、小字号的说明卡片，弹窗内容自然向下延伸，保存和取消按钮随之下移。
3. 说明卡片继续显示标题“失败重试间隔”和现有说明文字，右上角保留“×”关闭按钮。
4. 再次点击问号或点击“×”时收起卡片；同一弹窗内最多显示一张该说明卡片。
5. 展开和收起不改变用户已经输入的主地址、备用地址、重试数值和单位，也不触发保存。
6. 说明卡片使用方案 A 的浅蓝灰背景、细边框和紧凑间距，不使用新的系统弹窗或页面跳转。

## 验收

- 自动化测试确认点击问号前卡片隐藏，点击后卡片位于失败重试行之后，关闭后再次隐藏。
- 自动化测试确认展开卡片不会生成新的 `PopupWindow` 或 `AlertDialog`。
- 完整运行 `test`、`lintDebug`、`assembleDebug`。
- 安装到当前连接手机，打开测速地址弹窗并点击问号，真机截图确认说明紧邻重试设置且不遮挡其他内容。
