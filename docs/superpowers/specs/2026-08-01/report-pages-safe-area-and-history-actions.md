# 报告页面安全区与历史记录操作层级

## 目标

修复“历史诊断导出”“导入诊断报告”“比较诊断报告”“分析诊断报告”四个页面与系统状态栏、导航栏重叠的问题，并让历史记录的常用操作无需展开即可直接使用。

本次只调整 Android 端页面布局、文字摘要和按钮视觉角色，不修改诊断、采集、报告生成、导入、分析或比较的数据逻辑。

## 四个报告页面的系统安全区

四个报告页面统一读取 Android `WindowInsets`：

- 页面顶部基础间距叠加系统状态栏高度，标题不得与时间、信号、电量等内容重叠；
- 页面底部基础间距叠加系统导航栏高度，最后一项内容不得被返回、主页、最近任务三个导航键遮挡；
- 使用手势导航时，同样避开系统返回的底部手势区域；
- 不写死 K60 或 K80 的像素高度，页面随设备和导航模式自动适配；
- 重复分发 Insets 时以基础间距重新计算，不能不断累加。

## 历史诊断卡片

### 默认显示内容

每条历史记录默认按以下层级显示：

1. 实际开始时间到实际结束时间；
2. 报告文件名；
3. `时长 · 严格/标准模式 · 连接采集开启/关闭`；
4. `快照间隔 · 已完成/已中断`。

示例：

```text
2026-07-25 01:00 – 2026-07-25 07:00
20260725-0700-RedmiK60-23013RK75C-移动网络测试
360 分钟 · 严格模式 · 连接采集开启
5 分钟快照 · 已完成
```

报告文件名优先使用该诊断保存的 `reportBaseName`。为空时使用现有 `ReportActivitySupport.defaultBaseName` 规则生成可读默认名称，不再单独把 `23013RK75C` 作为这一行的主要内容。

### 默认操作

四个操作始终直接显示，不再依赖点击整张卡片：

- 分析报告；
- 导出报告；
- 修改文件名；
- 与其他报告比较。

四个按钮保持同级白底描边样式，使用两行两列布局。

### 查看详情

卡片标题区域右侧显示“查看详情”。点击后只展开统计摘要：

- 系统移动流量；
- 快照数量；
- 主动测速轮数；
- 连接记录数量；
- 媒体/通知证据数量。

展开后文字改为“收起详情”。再次点击则收起。加载详情不会隐藏、重复创建或移动四个操作按钮；点击操作按钮也不会触发详情展开。

## 历史记录选择窗口

比较和分析页面的“选择历史诊断”列表使用更完整的可读摘要：

- 报告文件名；
- 实际开始时间；
- 严格/标准模式；
- 已完成/已中断。

不再以系统状态英文值和设备型号代码作为主要识别内容。

## 比较与分析页面按钮

以下按钮统一为方案 A 的白底灰色描边 `NEUTRAL` 样式：

- 比较诊断报告：报告 A 和报告 B 中的“从历史记录选择”“从本地选择（最近 / 浏览）”；
- 分析诊断报告：“从历史记录选择”“从本地文件选择（最近 / 浏览）”。

按钮的点击回调、历史记录选择逻辑和系统文件选择器逻辑保持不变。

## 验收标准

- 四个页面在状态栏和三键/手势导航下均保留正确安全间距；
- 历史卡片初始状态即可看到报告文件名和四个操作按钮；
- 只有“查看详情”负责展开统计摘要；
- 操作按钮点击不会误触发详情展开；
- 历史选择列表显示报告名称和中文状态摘要；
- 比较与分析页面的数据来源按钮颜色一致；
- Robolectric 回归测试、全量单元测试、Lint 和 Debug APK 构建通过；
- 覆盖安装前确认设备没有 `RUNNING` 或 `FINALIZING` 诊断，安装后日志无本应用崩溃。
