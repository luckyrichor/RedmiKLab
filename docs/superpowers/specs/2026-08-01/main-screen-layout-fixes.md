# 主页面布局修复规格

## 目标

在不改变诊断、计划、报告及权限逻辑的前提下，修复 K60/K80 主页面三个视觉问题，并继续沿用已批准的方案 A。

## 已确认设计

1. “安排夜间诊断”使用白底、灰蓝描边的 `NEUTRAL` 样式，与右侧“取消已计划的夜间诊断”及“报告与数据分析”按钮保持一致；“立即诊断”继续作为唯一蓝色主操作。
2. 每个板块标题使用独立标题行：彩色竖线和标题文字在同一固定高度容器内垂直居中；标题行的下间距作用于整行，不再只作用于文字。
3. 主页面标题区域根据系统状态栏顶部 inset 增加安全内边距；页面底部继续根据导航栏 inset 增加安全内边距。

## 验收

- 自动化测试确认夜间计划两个按钮及四个报告按钮均为 `NEUTRAL`。
- 自动化测试确认板块竖线和标题共享同一标题行并垂直居中。
- 自动化测试确认状态栏 inset 会增加标题区域顶部 padding。
- `test`、`lintDebug`、`assembleDebug` 全部通过。
- 安装到当前 K60 后，真机截图确认顶部不重叠、板块标题对齐、按钮颜色一致。
