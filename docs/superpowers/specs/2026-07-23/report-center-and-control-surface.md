# RedmiKLab 控制台与报告中心设计规格

## 目标

在不改变夜间诊断、快照、主动测速、连接级采集和网络守护逻辑的前提下，重构手机端控制页面，并把“最近一次 ZIP 导出”扩展为可管理、可导出、可比较、可分析的历史报告中心。

同一 APK 必须继续兼容 Redmi K60 与 Redmi K80。

## 主页面信息架构

顶部保留项目标题、当前诊断窗口和运行模式状态。下方操作区可独立滚动，并按卡片分为：

1. 诊断参数
2. 诊断与采集模式
3. 系统权限与后台能力
4. 立即运行
5. 夜间计划
6. 报告与数据分析

报告入口为：

- 历史诊断导出
- 导入诊断报告
- 比较诊断报告
- 分析诊断报告

“开始诊断”改名为“立即诊断”，“导入另一台手机的报告并比较”改名为“导入诊断报告”。

## 参数设置交互

诊断参数均以摘要设置项呈现，不再常驻显示编辑框：

- 设置快照间隔
- 设置测速地址（主页面摘要显示“2 个地址”）
- 设置开始时间
- 设置结束时间
- 设置输出文件名

每项点击后在当前页面弹出设置窗口，包含“保存”和“取消”。

### 快照间隔

提供既定默认值供选择，并保持原有 1–60 分钟校验。运行中的诊断继续使用启动时锁定的配置。

### 测速地址

分别显示主地址、备用地址，并说明其用途。失败重试间隔由数值输入和单位选择组成，单位支持秒、分、时，保存时统一换算为后端现有的秒数并执行 0–300 秒校验。

### 开始与结束时间

- 使用 24 小时制。
- 明确提示诊断窗口最长 6 小时。
- 支持滚轮选择与手动输入。
- 两种输入方式都必须预填当前配置值。
- 用户只要打开设置项，即继续视为“已设置”；确认默认值也有效。

### 输出文件名

设置窗口包含基础名称与格式选择。格式仅提供：

- `.zip`
- `.json`
- `.html`
- `.pdf`

名称会移除非法字符，扩展名由格式选择统一附加。系统仍按“确认过结束时间优先、否则确认过开始时间、否则打开页面时的当前时刻”生成默认名称，用户可再次修改。

## 帮助说明

每个设置项或模式项的左侧文字后紧邻一个小型圆形问号。点击后在当前 Activity 上显示轻量说明浮层：

- 不跳转页面；
- 使用较小字号；
- 右上角有关闭按钮；
- 解释当前选项的含义、影响与限制。

## 模式和权限

模式区以紧凑开关或设置行呈现：

- 标准模式 / 严格模式
- 连接级采集
- 精确夜间采样闹钟

权限区包含：

- 应用流量统计
- 媒体与通知详情（可选）
- 后台诊断不受电池限制
- 闹钟和提醒权限

权限页面跳转和后端行为保持不变。

## 进程内提示

“正在启动/维持物理移动网络”的临时页面提示，每个 App 进程生命周期最多显示一次：

- 同一进程中从其他 App 或系统设置返回，不重复显示；
- 用户清除进程后再次启动，可重新显示一次；
- 前台服务通知持续存在，不受此规则影响。

## 文件名生命周期

每条诊断记录新增：

- 默认报告基础名称；
- 首选导出格式。

规则如下：

1. 尚未开始诊断时，主页面修改的是下一次诊断模板。
2. 诊断开始时，把当前名称与格式复制到新 Run。
3. 诊断运行中，主页面修改同步到当前 Run。
4. 诊断结束后，主页面修改不追溯修改旧 Run，只影响下一次诊断。
5. 在历史记录中修改名称或在导出窗口中修改名称/格式，会永久更新所选 Run。
6. 已经导出到文件系统的旧文件不自动改名。

数据库升级必须保留所有既有诊断数据。

## 历史诊断导出

历史记录按完成时间倒序，包含 `COMPLETED` 与 `INTERRUPTED` 记录。列表摘要展示：

- 日期和实际起止时间；
- 时长；
- 手机型号；
- 标准/严格模式；
- 是否开启连接级采集；
- 快照间隔；
- 完成状态。

点击记录后展开统计摘要和四个操作：

- 分析报告
- 导出报告
- 修改文件名
- 与其他报告比较

“与其他报告比较”进入同一个比较页面，并自动把该记录填入报告 A。

## 导出格式

### ZIP

保持现有完整离线报告包，继续包含 HTML、JSON 和各类 CSV 明细。

### JSON

生成单一、完整、结构化、可导入的 JSON，包含诊断记录、摘要、快照、测速及尝试、应用流量、连接流、事件、媒体/通知证据、分层记账、网络生命周期和采集盲区。

### HTML

生成无需联网即可打开的单文件报告，包含摘要、图表、发现和重要明细。

### PDF

生成固定布局的可读摘要报告，包含关键指标、结论、图表概览与重要明细；无需包含全部海量连接原始行。

## 导入、比较与分析

### 导入诊断报告

仅接受 ZIP 和 JSON。HTML 与 PDF 仅用于查看和分享，选择时应明确提示不支持分析导入。

### 比较诊断报告

报告 A 与报告 B 可分别来自：

- App 历史记录；
- Android 系统文件选择器（“最近”或“浏览”）。

任意组合均可，比较过程只读，不修改原报告。

### 分析诊断报告

数据同样可来自历史记录或本地 ZIP/JSON。页面明确显示“仅支持 ZIP 和 JSON 格式”，并提供：

- 关键指标；
- 信号与时间趋势；
- 流量构成图；
- 重要表格；
- 基于本地规则和报告证据生成的文字分析。

分析不得把相关性描述成因果，不依赖联网或外部 AI。

## 验收条件

- 原夜间诊断后端行为无回归。
- 数据库从版本 14 无损升级。
- 四种导出格式均可生成，ZIP/JSON 可再次导入。
- 可导出任意一条终态历史记录。
- 比较支持历史/文件任意组合，历史入口可预填报告 A。
- 分析支持历史/文件并拒绝 HTML/PDF 导入。
- 同一进程中连接采集临时提示只显示一次。
- 下方操作区在 K60/K80 上可滚动且不被导航栏遮挡。
- 全量单元测试、Lint、Debug 构建通过，并在安装前确认手机不存在运行中或正在结算的诊断。
