# 导出命名与状态栏修复设计

## 范围

恢复 MainActivity 的标准系统状态栏显示，并改善报告 ZIP 的建议文件名。

## 状态栏

- 主题明确声明非全屏、绘制系统状态栏和浅色状态栏图标。
- Activity 创建时清除全屏标志，并在 Android 11 及以上显式请求显示状态栏。
- 该修复不改变诊断运行期间的前台服务通知。

## ZIP 建议文件名

文件名输入框显示完整建议名，格式为：

`yyyyMMdd-HHmm-RedmiKLab-设备型号-自定义说明.zip`

时间选择规则为：用户点开过结束时间按钮时使用结束时间；否则用户点开过开始时间按钮时使用开始时间；两个按钮都没有点开时使用页面生成建议名的当前时刻。即使用户在时间选择器中取消或保持默认值，只要点开按钮也记录为已设置。输入框的每次用户编辑均自动保存；导出直接使用输入框的当前内容，只有输入框为空时才在导出时自动生成名称；非法文件名字符替换为下划线。
