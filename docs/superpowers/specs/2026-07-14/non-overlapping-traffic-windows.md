# 连续不重叠应用流量窗口设计

## 目标

每一条应用流量记录只覆盖诊断运行期间的一个连续时间段。所有成功取得的窗口可以相加为该诊断的总流量，不再包含诊断开始前的五分钟，也不与结束快照或相邻快照重叠。

## 时间边界

- 诊断启动时，以实际启动 `Instant` 作为首个窗口的起点。
- 每次快照以系统读取到的实际快照时间作为该窗口终点，并把该终点保存为下一窗口的起点。
- 结束事件产生最终快照；其窗口从上一条快照终点延续到最终快照时间，即使不足五分钟也照常写入。
- 网络状态快照仍可写入；若系统应用流量查询失败，快照保留失败状态，不能将缺失流量当成零。

## 报告

- `traffic.csv` 继续输出每条记录的 `window_start` 与 `window_end`，它们现在可直接按时间顺序相接。
- “流量最高应用”按同一包名的全部窗口字节数累计后再排序，而不是选取某一条单独窗口。
- 所有流量仍标为系统提供的时段级近似统计。
