# K60 夜间诊断运行加固

## 目标

根据 K60 在 2026-07-17 01:00 至 07:00 严格模式真机报告暴露的问题，加固现有短任务与连接级采集架构，不重写已经验证可用的诊断流程。同一 APK 继续兼容 K60 与 K80。

## 已确认问题与根因

1. 结束、恢复和安全检查闹钟在同一时刻获得运行机会时，`NightDiagnosticService` 为每个命令创建独立线程。多个线程可能同时读取到 `RUNNING`，从而重复生成最终快照和完成事件。
2. 网络快照只检查 `ConnectivityManager.activeNetwork`。连接级采集启用后默认网络是本地 VPN，即使底层中国电信蜂窝网络可用，也会被记录为非移动网络。
3. K60 把 06:58 安全检查、07:00 结束和恢复闹钟延迟到 07:01:42 一起交付。严格模式已持有 CPU 唤醒锁，却仍把结算完全交给厂商可能延迟的系统闹钟。
4. 主动测速要求蜂窝网络同时具有 `INTERNET`、`NOT_RESTRICTED` 和 `VALIDATED`。锁屏及本地 VPN 场景下，底层蜂窝网络可能仍可传输数据但暂时没有 `VALIDATED` 标记，因此测速在 DNS 前直接失败。
5. HTTPS 下载在已经收到部分数据后发生异常时，异常分支统一写入零字节，导致报告和预算都少计实际流量。
6. 严格采样的 Handler 在每次任务完成后再延迟一个完整间隔，任务执行耗时会逐轮累加到实际采样延迟中。

## 方案

### 动作串行化与终态幂等

- `NightDiagnosticService` 的所有启动命令进入同一个单线程执行器，保持到达顺序，不再为每个命令创建独立线程。
- 完成事件只在 DAO 的条件更新实际改变一条 `RUNNING` 记录后写入。
- 最终快照继续按 Run ID、计划时间和触发来源去重；串行执行确保“检查后插入”不会发生同进程竞争。
- 服务销毁时安全关闭执行器；每个 `startId` 只在自身动作完成后停止。

### 统一蜂窝网络识别与获取

- 新增可独立测试的蜂窝网络候选策略：必须是 `TRANSPORT_CELLULAR` 且具有 `INTERNET`；优先 `VALIDATED`，其次选择尚未验证但仍可尝试的蜂窝网络。
- 网络快照遍历 `allNetworks` 判断底层蜂窝网络，不再仅依赖 VPN 默认网络。
- 主动测速先从现有候选中选择；没有候选时，通过 Android 网络请求短暂等待蜂窝网络出现，然后绑定该网络进行 DNS 与 HTTPS。
- 报告保留阶段化失败信息，使无候选、请求超时、DNS、TLS/连接和下载中断可以区分。

### 严格模式绝对时刻与双通道结算

- Handler ticker 以单调时钟的绝对 deadline 重新投递，下一轮 deadline 基于最初基准递增，不基于上一轮执行完成时刻。
- 严格模式附着时，同时在持有唤醒锁的 VPN 服务内部安排结束前 120 秒检查和正式结束动作。
- 系统精确闹钟继续保留，作为进程重启和 VPN 服务异常时的后备通道。
- 内部 deadline 与系统闹钟可能同时到达，但动作串行化和终态幂等保证只结算一次。
- 重新附着或恢复时根据持久化的计划结束时间重新计算未来 deadline；已过结束时间则立即请求结算。

### 失败测速流量记账

- DNS、HTTPS 首包和已读取字节在执行过程中分别保存。
- 下载异常返回失败结果时保留已经读取的字节、已完成阶段耗时，并在每次尝试、整轮结果及预算中如实累计。
- 失败仍不计算下载速率，避免把不完整样本当作有效测速结果。

## 测试与验收

- 单元测试复现并证明多个结束命令只产生一次完成结果。
- 单元测试覆盖 VPN 为默认网络但底层蜂窝网络存在、优先已验证候选、无验证候选时允许尝试以及等待网络超时。
- 单元测试模拟输入流读取部分字节后抛错，确认失败结果保留实际字节。
- 单元测试模拟任务自身耗时，确认严格采样仍以绝对计划时刻调度。
- 单元测试覆盖严格模式安全检查、结束 deadline、重复回调和恢复附着。
- 运行全量 Gradle 单元测试、Android Lint 和 Debug APK 构建。
- 安装到当前连接的 K60，验证安装成功、App 可启动且没有立即崩溃；长达六小时的锁屏时序效果留给下一次夜间真机报告最终确认。

## 边界

- 不取消系统精确闹钟，也不承诺 Android 系统级硬实时；严格模式通过既有唤醒锁和内部 deadline 显著降低厂商闹钟延迟影响。
- 不绕过本地 VPN 的安全边界，不引入 Root，不保存数据包正文。
- 不修改用户已经确认的主备测速端点、5+5 次重试、10 秒间隔和 1 GB 夜间预算。
